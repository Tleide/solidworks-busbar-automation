# 铜排自动建模架构设计

本文档记录当前铜排自动建模主线的规则。历史 demo、旧扫掠路线和版本化命名已经移除，当前代码已经拆成 `App`、`Domain`、`Rules`、`Planning`、`Reporting`、`SolidWorks` 等目录，后续开发应在当前主线中扩展规则和模块。

## 1. 建模原则

- 所有铜排统一使用 2D 开放轮廓中心线 + Sheet Metal Base Flange。
- 铜排宽度方向统一使用 SolidWorks 的真实 `MidPlane`。
- 草图线代表铜排宽度中心线，不再通过人工宽度偏移修正装配位置。
- 默认折弯半径 `5mm`，默认 K 因子 `0.47`。
- 连接点代表孔中心，端部裕度由孔中心向铜排端部外伸。
- 同侧/异侧先作为拓扑关系判断，再由拓扑关系决定是否做厚度补偿。

### 1.1 钣金规则快照

`BusbarSettings` 是生成前的输入配置。`BusbarPlanBuilder` 在建立 `BusbarPlan` 时，将折弯半径、K 因子、宽度生成侧和加厚方向解析并固化到每根 `Busbar.SheetMetal`。此后 SolidWorks 建模层和生产报表都只读取该快照，不能再回读全局 `Settings` 中的钣金参数。

这保证同一轮生成中实体、预检和报表使用同一份 R/K/宽度方向数据；后续 UI 修改参数时，应先重新建立计划，再执行生成或导出报表。

## 4. SolidWorks API 经验

开放轮廓钣金两侧对称不能用 `Dist1=Width/2`、`Dist2=Width/2` 模拟。当前正确约定是：

```text
Dist1 = Width
Dist2 = 0
EndCondition1 = swEndCondMidPlane
EndCondition2 = swEndCondBlind
DirToUse = 1
```

孔切除当前最可靠流程：

```text
按实体表面计算孔草图平面
-> 打开草图并画圆
-> 使用贴合面确定唯一切除方向
-> 以铜排厚度执行单向 FeatureCut4
-> 如果 active sketch 入口不可用，只改用已创建的 sketch feature 选择入口，切除方向、深度和作用域保持不变
```

禁止通过反转方向、改变 normal-cut 或改变 feature scope 反复试切。特征创建成功后还要检查实体圆柱面是否在计划孔中心、半径和轴向上匹配，并实际跨越完整材料厚度。

## 5. 当前主对象

| 对象 | 含义 |
| --- | --- |
| `FoundPoint` | 从 SW 扫描得到的命名参考点，坐标已转换到装配体坐标。 |
| `ConnectionPort` | 可连接铜排的工程端口，包含孔中心、贴合面、引出方向、裕度、孔径。 |
| `CollectorLayout` | 某相汇流排的中心位置、方向、长度和 Tap 端口。 |

## 6. N 相规则

- N 相当前只生成汇流排和分支排。
- 若没有任何 `N_IN`，跳过 N 相生成。
- 若只存在部分 `N_IN`，直接报错，避免生成不完整 N 排。
- N 排规格独立于 ABC，可后续接入标准校核和自动选型。
- N 分支排规格和拓扑规则独立于 ABC；当前 N 规则全部为 `Single`，ABC 则由每个额定电流的规则决定。

## 6.1 漏保额定电流分支排选型

ABC 分支排不再统一使用一个固定规格。系统在识别漏保组件时，从组件名称中匹配已配置的额定电流规则，并把该漏保的铜排规格和默认单双排方式保存到 `LoubaoGroup`。

当前代码内规则为：

| 额定电流 | 分支排规格 | 默认拓扑 |
| --- | --- | --- |
| `250A` | `4 x 20mm` | `Single` |
| `400A` | `4 x 30mm` | `DoubleClamp` |
| `630A` | `4 x 40mm` | `DoubleClamp` |

组件名称必须包含且只包含一个已配置的独立电流标记，例如 `PGM8LZ-400-1` 或 `PGM8LZ-400A-1`。程序只匹配已配置的 `250/400/630` 标记，不会把型号中的 `8` 或实例编号 `-1` 当作电流。名称缺少匹配规则或包含多个匹配值时会停止规划并报错。

`PhaseBranchArrangementOverride` 可作为项目级强制覆盖：为 `null` 时使用每台漏保规则中的默认单双排；设置为 `Single` 或 `DoubleClamp` 时，统一覆盖所有 ABC 漏保的拓扑，但不改变各自的铜排规格。

每台漏保自己的 `BusbarProfile` 同时参与汇流排长度范围、搭接孔矩阵、下排高度、上排 Z 向错层和外侧避让路径计算，不能只在最后创建零件时替换规格。

N 排使用独立的 `NeutralBranchRules` 输入，不复用 ABC 的 `PhaseBranchRules`。当前 N 规则为：

| 额定电流 | N 分支排规格 | 默认拓扑 |
| --- | --- | --- |
| `250A` | `4 x 20mm` | `Single` |
| `400A` | `4 x 30mm` | `Single` |
| `630A` | `4 x 40mm` | `Single` |

`NeutralBranchArrangementOverride` 为 `null` 时使用每台漏保的 N 规则；后续如需项目级统一强制单双排，可单独设置该覆盖值，不会影响 ABC 配置。

## 7. 铜排搭接孔位规则

当前已加入第一版搭接孔位规划，位置在 `Planning` 层：先生成搭接中心 Tap，再由 `BusbarOverlapHolePlanner` 按矩阵展开为实际孔位，最后 `SolidWorks/MountingHoleBuilder.cs` 只按 `MountingPorts` 执行打孔。

当前规则来源于根目录 `铜排搭接逻辑.xlsx`，代码内由 `Rules/BusbarOverlapRuleMatrix.cs` 固化一份 30/40/50/60 宽度组合矩阵：

| 宽度组合 | 规则 |
| --- | --- |
| `30x30` | 单孔，孔径 11mm |
| `30x40`、`40x30`、`40x40` | 单孔，孔径 13mm |
| `50x50` | 斜双孔，孔径 13mm，贴合面内偏移 `±11mm, ±11mm` |
| `60x60` | 斜双孔，孔径 13mm，贴合面内偏移 `±12mm, ±12mm` |
| 其余矩阵内组合 | 直双孔，孔径 11mm，沿窄排长度方向偏移，偏移量为宽排宽度的四分之一 |

暂时只批准 `30/40/50/60mm` 的组合。未覆盖规格会直接终止规划，不再生成中心孔兜底；宽度只有在距离整数不超过 `0.01mm` 时才允许归一化。当前 `250A -> 4 x 20mm` 分支排没有批准的 `20x50/20x60` 搭接规则，因此包含 250A 漏保的装配会在预检前停止，必须先补充并确认规则矩阵。

## 8. 分支排双排夹接

当前由 `PhaseBranchRules` 和 `NeutralBranchRules` 分别给每个额定电流配置 ABC、N 分支排规格与默认拓扑；`PhaseBranchArrangementOverride` 和 `NeutralBranchArrangementOverride` 可选地做项目级强制覆盖：

- `Single`：每个漏保进线点生成一根传统分支排。
- `DoubleClamp`：每个漏保进线点生成 `_Lower`、`_Upper` 两根分支排，分别夹接在汇流排下表面和上表面。

当前默认配置中，400A/630A 的 ABC 为 `DoubleClamp`，250A 的 ABC 为 `Single`，N 排全部为 `Single`。上排起点错层方向由 `DoubleClampUpperStartZSign` 控制；当前值 `-1` 表示从漏保处先向 `Z-` 偏移一个分支排厚度。

ABC 双排中的 `_Upper` 是 Z-方向外侧排。它在已错层的起点上采用专用避让路径：先沿 `Y+` 引出 `DoubleClampOuterInitialRiseMm`，再沿 `Y+ / Z-` 斜向外伸，斜段的额外 Z 投影固定为 `2 × 分支排厚度`，实际长度不小于 `DoubleClampOuterDiagonalMinimumLengthMm`，随后沿 `Y+` 到达原有搭接高度，最后沿 `Z+` 回到原有汇流排搭接点。默认首段和斜段最小实际长度均为 `50mm`。起点、终点、搭接高度和最终 Z 坐标保持不变。

若起终点可用的 Y 高度不足以容纳首段和斜段，规划会报出明确的约束冲突，不会缩短斜段来勉强生成。

双排夹接的高度和打孔基准面必须以 SolidWorks 实际生成实体的表面方向为准，不能按“路径天然位于厚度中面”推导。经边界框实测，当前后端中汇流排路径位于上表面，分支排搭接端路径位于下表面。

完整的实体方向、上下排高度公式、孔草图平面规则、已踩过的错误和验证步骤见 [双排夹接实现与几何验证记录](DOUBLE_CLAMP_IMPLEMENTATION_NOTES.md)。

汇流排本体只采用一套搭接孔位；上、下分支排各自在自己的铜排上建立对应孔位，不重复在汇流排上创建重叠的切除特征。

## 10. 生成前预检

`Planning/BusbarPreflightValidator.cs` 是生成前的独立校验层。它消费已经生成的 `BusbarPlan`，检查规划输出是否满足配置和几何契约；不会再次调用 `BusbarRoutePlanner` 生成第二套路径，也不会调用 SolidWorks 建模 API。

可在 PowerShell 中执行：

```powershell
TopToDown.exe --validate
```

该模式会连接当前 SolidWorks 装配、扫描参考点、生成 `BusbarPlan` 并输出分级报告，但不会删除已有 `Busbar_*` 组件、不会创建零件、不会保存或修改装配。报告包含 `INFO`、`WARNING`、`ERROR` 和汇总结果。没有激活装配、参考点缺失或额定电流无法解析时，也会以 `ERROR` 形式输出。

正常生成同样会先执行预检，只有没有 `ERROR` 才会进入钣金建模。未批准的搭接宽度组合属于阻断错误；例如 `20mm` 分支排不会得到中心孔兜底。旧铜排不会在预检后立即删除，而是在新零件全部生成、暂存插入并通过实体校验后才删除。

当前预检覆盖：

- 选型表完整性、重复额定电流、宽度/厚度和单双排配置。
- 漏保名称解析后的 ABC/N 选型是否与配置表一致。
- 汇流排规格、长度范围、分支排数量和单/双排拓扑是否一致。
- 分支排与汇流排的搭接孔规则覆盖，以及规划出的 X/Z 孔位是否成对存在。
- 双排夹接的上下排终点高度、起点 Z 错层、外侧上排斜向避让路径约束。

它不替代生成后的实体校验。钣金基体、孔草图平面、切除深度、实体边界框和实际干涉仍需要在 SolidWorks 生成后检查；后续 UI 只需读取同一个 `BusbarPreflightReport` 对象即可展示结果，而不应复制校验规则。

## 11. 生成后实体校验

`SolidWorks/BusbarGeometryVerifier.cs` 是独立于预检的只读实体校验层。它在装配坐标系中读取已插入的 `Busbar_*` 组件和零件特征，不创建、删除、移动、重建或保存实体。

```powershell
TopToDown.exe --verify-geometry
```

该命令先按当前参考点重建期望的 `BusbarPlan`，再把计划与已经存在的实体逐项比对。没有铜排时，它会逐根报告缺失组件；不会自动生成。正常生成流程会先校验本轮暂存组件，确认通过后替换旧件，再对最终装配执行同一校验器。

当前实体校验内容：

- 每个选中的计划铜排是否恰好存在一个装配组件。
- 分支排和主排实际 X 向宽度是否等于选型规格；汇流排实际 Y 向厚度和 Z 向宽度是否等于规格。
- 每个命名孔切除特征是否存在，并通过 `ExtrudeFeatureData2.GetDepth(...)` 验证声明切除深度不少于材料厚度。
- 遍历实际实体的圆柱面，核对孔中心、半径、轴向和沿厚度方向的物理跨度，防止“切除特征存在但只打通一半”。
- 对 ABC 每一组双排夹接，读取实际实体边界框并验证：下排最高面等于汇流排下表面，上排搭接端下表面等于汇流排上表面。

未来如果修改钣金基体、草图平面、切除 API 或分支路径，应重新运行真实 SolidWorks 小样；自动校验会检查当前已覆盖的表面关系、规格和孔贯穿条件，但不能替代装配干涉与工艺可制造性检查。

## 12. 搭接螺栓长度校核

当前已将标准件目录中的螺栓、垫圈和螺母尺寸接入生成前规划。校核范围先限定为铜排与汇流排之间的搭接连接，因为这些连接的夹紧层厚度在当前模型中是完整可知的；漏保端子厚度尚未进入数据层，因此暂不对设备端连接做假设性计算。

当前装配顺序为：

```text
螺栓头 -> 平垫 -> 铜排/汇流排夹紧层 -> 平垫 -> 弹垫 -> 螺母
```

螺栓表中的长度按公称长度处理，即螺栓头下表面到螺栓末端，不包含螺栓头高度。最小螺纹露出量当前固定为 `3mm`：

```text
所需公称长度 = 夹紧层总厚度
             + 头侧平垫厚度
             + 螺母侧平垫厚度
             + 弹垫压平厚度
             + 螺母高度
             + 3mm
```

程序从该规格的标准长度中选择不小于所需长度的最短值，并重新计算实际露出量。实际露出量可能大于 `3mm`，后续纵向电气间隙必须使用实际值。

双排夹接的下排、汇流排和上排会被视为同一根贯穿螺栓的夹紧层，不能误算成两套独立螺栓。

## 13. 生产清单与加工清单

`Reporting/ProductionReportExporter.cs` 以 `BusbarPlan` 为唯一数据源导出 Excel 工作簿，不调用 SolidWorks 建模 API。它包含七个工作表：

- `说明`：报表生成口径、铜排/孔/折弯/螺栓总量。
- `漏保选型`：每台漏保的额定电流、ABC/N 分支铜排规格与单/双排拓扑。
- `铜排汇总`：按厚度 x 宽度汇总数量、长度、折弯数和孔数。
- `铜排明细`：每根铜排的规格、起终端、路径长度、估算展开长度、折弯数和孔数。
- `钻孔清单`：每一根实体铜排上的孔径、用途和装配体坐标。
- `标准件汇总`：螺栓、平垫、弹垫和螺母的需求数量。
- `螺栓明细`：每个搭接孔的螺栓选型、夹紧层厚度、所需长度与实际露出量。

使用方式：

```powershell
TopToDown.exe --export-report
```

该命令会扫描当前已激活装配体、生成计划与预检报告，然后仅导出 `Reports/Busbar_ProductionReport_yyyyMMdd_HHmmss.xlsx`，不删除、创建、移动或保存装配体零件。完整铜排生成成功并通过实体校验后，程序也会自动导出同一份完整计划的生产报表；使用 `--only` 局部建模时不会自动导出，避免把局部结果误认为完整 BOM。

### 长度口径

`SheetMetalSketchLine` 是实际用于 SolidWorks 钣金建模的路径，它已经包含连接孔外的端部余量，因此报表的“草图中心线长度”以它为准。程序同时计算“估算展开长度”：对每个折弯点，取中性层半径 `R + K x t`，将尖角折线替换为中性层圆弧：

```text
估算展开长度 = 草图中心线折线总长
             + Σ [ (R + K x t) x 转角 - 2 x (R + K x t) x tan(转角 / 2) ]
```

这里的 `R`、`K`、`t` 分别为当前铜排的折弯半径、K 因子与厚度。该值适用于当前规划阶段的备料估算，但最终车间下料仍应以未来从 SolidWorks `Flat Pattern` 直接读取的展开长度为最终依据。

## 14. 分阶段替换旧组件

正常实体生成由 `SolidWorksBusbarPartBuilder` 和 `GeneratedComponentManager` 协作完成：

```text
逐根生成 SLDPRT 文件（唯一时间戳文件名）
-> 每根保存后在零件文档仍打开时，以 StagedBusbar_* 临时名称插入装配体
-> 插入完成后关闭该零件文档，再生成下一根
-> 对暂存组件执行尺寸、孔贯穿和双排贴合校验
-> 暂存校验失败：删除本轮组件和本轮文件，旧组件保持不动
-> 暂存校验通过：重命名新组件，再删除旧 Busbar_* 组件
-> 重建并执行最终装配校验
```

这是在 SolidWorks API 能力范围内的分阶段替换，不是数据库事务。它保证建模或暂存校验失败时不会先删旧件；但旧件删除开始后，SolidWorks 不提供通用的原子回滚，因此仍应保存装配体版本并检查最终校验结果。

## 15. 自动化测试边界

`C#/TopToDown/TopToDown.Tests` 当前覆盖命令行严格解析、搭接规则矩阵、双排厚度补偿和螺栓连接点容差分组：

```powershell
dotnet test C#/TopToDown/TopToDown.Tests/TopToDown.Tests.csproj -c Release
```

这些测试不依赖 SolidWorks，适合在每次规则和规划修改后快速运行。SolidWorks COM 调用、真实钣金方向、孔圆柱面和装配贴合仍必须通过打开装配体后的局部生成或完整生成验证。
