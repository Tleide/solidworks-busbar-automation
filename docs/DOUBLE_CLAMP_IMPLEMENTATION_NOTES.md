# 双排夹接实现与几何验证记录

本文记录 2026-07-12 对分支排双排夹接、汇流排孔位和 SolidWorks 钣金实体方向的实际验证结论。这里的公式来自已生成实体的边界框测量，不是针对某一组参数的临时偏移量。

## 1. 范围

双排夹接指同一个设备端口引出两根独立分支排：

- `_Lower` 从汇流排下方贴合汇流排下表面。
- `_Upper` 从汇流排上方贴合汇流排上表面。
- 为避免两根分支排在设备侧穿模，`_Upper` 的整个起点沿 Z 方向偏移一个分支排厚度；当前默认方向为 `Z-`。

两根分支排分别生成路径和孔位，但搭接到同一汇流排时使用同一套汇流排孔位，不应在汇流排上重复创建重叠的孔特征。

## 2. 最重要的经验

### 2.1 不要把 Sheet Metal 的 MidPlane 理解为厚度中心面

本项目中 `MidPlane` 用于控制开放轮廓钣金的宽度方向。它并不意味着路径线一定落在铜排厚度的中面。SolidWorks API 的特征参数、草图平面和拉伸方向组合变化后，路径对应的实体表面也可能变化。

因此，修改 `InsertSheetMetalBaseFlange2` 参数或草图基准面后，必须重新生成样件并通过实体边界框确认真实的表面位置，不能仅从参数名称推断。

### 2.2 一个 ConnectionPort.Y 不能同时代表三种几何含义

以下坐标必须明确区分：

- 搭接/电气逻辑参考位置。
- 钣金路径在搭接端的终点位置。
- 实体表面上的孔草图基准面位置。

此前将端口的 `HoleCenter.Y` 同时用作这些位置，造成孔草图离实体表面半个分支排厚度，切除只能得到半孔或孔位落在实体外。

### 2.3 孔型规则和孔草图平面是独立问题

`BusbarOverlapHolePlanner` 只负责搭接规范中的孔数、孔径和贴合面内的 X/Z 偏移（单孔、直双孔、斜双孔）。它不决定孔草图的 Y 坐标，也不应关心 SolidWorks 的实体生成方向。

孔草图平面与切除方向由 `SolidWorks/MountingHoleBuilder.cs` 根据实际铜排实体表面处理。

## 3. 已验证的实体方向

定义：

```text
C  = 汇流排路径 Y，也就是汇流排上表面 Y
Tc = 汇流排厚度
Tb = 分支排厚度
R  = 分支排搭接端路径 Y
```

本后端当前实际生成结果为：

```text
汇流排：路径位于上表面，实体 Y 范围为 [C - Tc, C]
分支排：搭接端路径位于下表面，实体 Y 范围为 [R, R + Tb]
```

这两个结论来自 `PartDoc.GetPartBox(false)` 的实体边界框日志。它们是确定双排高度、孔草图基准面和切除方向的前提。

## 4. 双排夹接的最终高度公式

物理约束是：

```text
下排上表面 = 汇流排下表面
上排下表面 = 汇流排上表面
```

根据第 3 节的实体方向：

```text
lowerRouteEndY = C - Tc - Tb
upperRouteEndY = C
```

对应实体范围为：

```text
下排实体     = [C - Tc - Tb, C - Tc]
汇流排实体   = [C - Tc,      C]
上排实体     = [C,           C + Tb]
```

三者端面连续贴合：无 Y 向间隙，也不以穿模方式伪造夹接效果。

例如 `C = 474mm`、`Tc = 8mm`、`Tb = 4mm` 时：

```text
下排路径终点 = 462mm，下排实体 = 462 ~ 466mm
汇流排实体   = 466 ~ 474mm
上排路径终点 = 474mm，上排实体 = 474 ~ 478mm
```

这些数值只是公式在当前规格下的验证样例，代码中不应写死 `462`、`474` 等结果值。

## 5. 孔草图平面和切除规则

### 汇流排孔

- 单孔、直双孔和斜双孔统一使用同一个真实汇流排上表面：`Y = C`。
- 从该表面向实体内部单侧盲切，切除深度为 `Tc`。
- 不再将直双孔放在实体中面后做单侧切除；那会只打穿半个实体。
- 也不应对全部孔强制双向切除；若斜双孔原本以实体表面为草图面，会导致切除方向和深度语义混乱。

### 下排搭接孔

下排路径位于下表面，搭接面是其上表面，因此：

```text
lowerHolePlaneY = lowerRouteEndY + Tb
```

### 上排搭接孔

上排路径本身位于下表面，搭接面就是该下表面，因此：

```text
upperHolePlaneY = upperRouteEndY
```

以第 4 节样例为例：下排孔草图面为 `466mm`，上排孔草图面和汇流排孔草图面均为 `474mm`。

## 6. 已出现过的错误及原因

| 现象 | 根因 | 最终处理 |
| --- | --- | --- |
| 汇流排直双孔只打了一半 | 草图基准面位于实体中面，却采用单侧切除 | 所有汇流排孔统一落在真实上表面，单侧切除厚度 `Tc` |
| 斜双孔也只剩半孔 | 为修复直双孔而把所有孔统一改为双向切除，破坏了表面草图孔的原逻辑 | 统一改为同一实体表面 + 单侧盲切 |
| 分支排孔草图离实体表面 `2mm` | 用逻辑端口 Y 代替实体真实表面；当前分支排厚度为 `4mm` | 根据分支路径末端和厚度推导实际孔面 |
| 上下分支排都比预期高一个分支排厚度 | 把路径误认为厚度中心线，并按中心面做补偿 | 以实际实体增长方向推导第 4 节公式 |
| 为了对齐而尝试移动汇流排 | 用整体位置掩盖分支路径推导错误 | 保持汇流排布局不变，修正分支路径终点公式 |

## 7. 当前代码职责

| 模块 | 职责 |
| --- | --- |
| `Planning/BusbarPlanBuilder.cs` | 用 `C`、`Tc`、`Tb` 计算上下分支排的路径终点；不写固定高度。 |
| `Planning/BusbarOverlapHolePlanner.cs` | 仅计算孔型、孔径及 X/Z 面内偏移。 |
| `SolidWorks/MountingHoleBuilder.cs` | 将孔位投影到真实铜排表面，并按实体厚度单侧切除。 |
| `SolidWorks/CadGeometryUtilities.cs` | 输出实体边界框，作为 API 几何语义变化后的验证手段。 |

`CreateRouteCenterlinePort` 这个历史命名容易让人误以为路径位于厚度中心。当前后端语义下，它承载的是钣金路径参考位置；后续重构时可以改名，但在未完成全局替换前不要据此假设其为实体中心线。

## 8. 验证步骤

建议只生成一个汇流排和一对夹接分支排，减少整套装配重建时间：

```powershell
TopToDown.exe --keep-existing --only=Busbar_A_Collector,Busbar_A_Branch_1_Lower,Busbar_A_Branch_1_Upper
```

检查控制台日志：

- 汇流排实体边界框的 Y 范围是否为 `[C - Tc, C]`。
- 下、上分支排路径终点是否分别满足 `C - Tc - Tb` 与 `C`。
- 下、上分支排孔草图平面是否分别为 `lowerRouteEndY + Tb` 与 `upperRouteEndY`。
- 汇流排孔草图平面是否为 `C`，切除深度是否为 `Tc`。

在 SolidWorks 中隐藏无关零件，使用侧视、剖视和等轴视图确认：

- 上下分支排与汇流排没有 Y 向缝隙或实体重叠。
- 上下分支排与汇流排的直双孔同轴。
- 单孔、直双孔和斜双孔均完整贯穿各自铜排厚度。

## 9. 后续防回归建议

- 若修改钣金基体法兰、草图平面或切除 API 参数，先重新做边界框验证，再调整规划公式。
- 后续可加入自动几何校验，至少断言：

```text
lowerBranchTop == collectorBottom
upperBranchBottom == collectorTop
branchHolePlane == branch physical contact surface
collectorHolePlane == collector physical surface
```

- 所有几何补偿必须来自实体表面约束和厚度关系。不要用固定 Y 值、视觉对齐或移动整个汇流排来掩盖推导错误。

## 10. 外侧上排斜向避让路径

2026-07-13 起，双排夹接中的 `_Upper` 定义为 Z-方向外侧排。它不是在原有简单折线路径上追加固定坐标，而是在规划层使用专用的 `DoubleClampOuterAvoidance` 路径模式生成。

### 10.1 保持不变的几何边界

- `_Upper` 的起点仍先从漏保搭接面沿 `Z-` 偏移一个分支排厚度 `Tb`。
- 最终搭接终点仍使用原有上排终点：Y 高度为汇流排上表面 `C`，最终 Z 坐标不变。
- 上排实体的下表面仍贴合汇流排上表面；本路径只改变中间避让形状，不改变第 4 节的夹接高度公式。

### 10.2 路径与参数

以已偏移后的上排起点为 `P0`，原有上排搭接终点为 `P4`，分支排厚度为 `Tb`：

```text
P0 -> P1: Y+ DoubleClampOuterInitialRiseMm
P1 -> P2: Y+ / Z- 斜段
P2 -> P3: Y+ 至 P4.Y
P3 -> P4: Z+ 回到原有搭接终点
```

斜段规则：

```text
额外 Z- 投影 Dz = 2 x Tb
斜段最小实际长度 L = DoubleClampOuterDiagonalMinimumLengthMm
斜段 Y+ 投影 Dy = sqrt(L^2 - Dz^2)
```

默认值：

```text
DoubleClampOuterInitialRiseMm = 50mm
DoubleClampOuterDiagonalMinimumLengthMm = 50mm
```

若可用高度 `P4.Y - P0.Y` 小于 `50mm + Dy`，规划会停止并报告约束冲突；不能通过压缩斜段来绕过最小工艺长度。

### 10.3 当前 4mm 分支排验证样例

当前 `Tb = 4mm` 时：

```text
起点错层 = Z- 4mm
斜段额外 Z- 投影 Dz = 8mm
斜段 Y+ 投影 Dy = sqrt(50^2 - 8^2) = 49.356mm
斜段实际长度 = 50mm
```

对 A 相第一个漏保的局部测试中，路径日志为：

```text
Y+ 50mm
-> Y+ 49.356mm / Z- 8mm
-> Y+ 141.444mm
-> Z+ 回到原汇流排搭接坐标
```

生成出的开放轮廓草图线在终点处仍到达 `Y = 474mm`，之后由端部裕度向 Z+ 延伸；这与汇流排上表面位置一致。

## 11. 2026-07-13 局部装配验证流程

为了观察双排夹接和外侧避让，不必每次重建整套柜体。当前推荐只生成一个汇流排和一对分支排；程序会先暂存并校验新三件，通过后再替换已有 `Busbar_*` 组件：

```powershell
TopToDown.exe --only=Busbar_A_Collector,Busbar_A_Branch_1_Lower,Busbar_A_Branch_1_Upper
```

注意：不带 `--keep-existing` 时，程序会清除装配中已生成的 `Busbar_*` 组件，得到干净的三件局部装配；带 `--keep-existing` 时会保留旧件，适合追加单件调试，但不适合目视检查干涉。

本次三件局部测试的实体边界框为：

```text
下排：    Y = 218.2 ~ 466mm
汇流排：  Y = 466 ~ 474mm
上排：    Y = 218.2 ~ 478mm
```

由此确认：

- 下排上表面与汇流排下表面在 `Y = 466mm` 贴合。
- 上排下表面与汇流排上表面在 `Y = 474mm` 贴合。
- 外侧上排的斜段没有改变双排夹接的最终高度关系。
- 汇流排、下排、上排的搭接直双孔均成功创建并按对应实体厚度贯穿。

## 12. 按漏保额定电流选型

2026-07-15 起，ABC 分支排不再统一使用一个全局规格。程序从漏保组件名称中严格匹配已配置的额定电流标记，并为每台漏保保存独立的分支排规格和默认单双排拓扑：

```text
250A -> 4x20mm, Single
400A -> 4x30mm, DoubleClamp
630A -> 4x40mm, DoubleClamp
```

名称解析只匹配已配置规则的独立字段，例如 `PGM8LZ-400-1` 或 `PGM8LZ-400A-1` 中的 `400`/`400A`。型号中的 `8`、装配实例后缀 `-1` 等其他数字不会被当成额定电流。名称没有唯一匹配的规则时，规划会停止并报错。

每台漏保的规格必须参与汇流排长度范围、搭接孔规划、双排高度、上排 Z 向错层和外侧避让路径。不能只在生成零件的最后一步替换宽厚值。

当前测试装配中按 X 排序后的 A 相三台漏保为 `630A`、`400A`、`400A`。局部生成 A 汇流排和三对分支排后，实际输出为：

```text
Busbar_A_Branch_1_Lower / Upper: 4x40mm, DoubleClamp
Busbar_A_Branch_2_Lower / Upper: 4x30mm, DoubleClamp
Busbar_A_Branch_3_Lower / Upper: 4x30mm, DoubleClamp
```

该结果验证了同一汇流排下混合规格的分支排可以分别规划。`20mm` 宽度目前不在搭接孔矩阵的批准范围内；当前实现已经取消中心孔兜底，因此包含 250A 单排的计划会直接报错并阻止生成。补充并确认 `20mm` 对应的搭接孔规则后，250A 才能恢复实体生成。

N 排不复用 ABC 选型表，而是拥有独立 `NeutralBranchRules` 输入。当前 N 的 `250A/400A/630A` 规则分别为 `4x20/4x30/4x40`，默认全部单排；即使与 ABC 当前宽厚数值相同，后续也可单独调整，不会影响主相。

2026-07-15 对当前测试装配的 N 排局部生成验证结果为：

```text
Busbar_N_Branch_1: 630A -> 4x40mm, Single
Busbar_N_Branch_2: 400A -> 4x30mm, Single
Busbar_N_Branch_3: 400A -> 4x30mm, Single
```

对应 N 汇流排 `5x50mm` 已按三台分支各自宽度计算长度，并生成 `40x50`、`30x50`、`30x50` 三组搭接直双孔。四件零件（N 汇流排加三根 N 分支排）的钣金和孔切除均已完成。

## 13. 双排夹接生成前预检

双排的高度和路径已经经过实体测量验证，但在每次生成前仍应检查规划结果是否继续满足这些公式。当前使用：

```powershell
TopToDown.exe --validate
```

该命令只扫描当前激活装配并输出报告，不删除 `Busbar_*`，不创建或重建任何铜排。对于每台配置为 `DoubleClamp` 的 ABC 分支，预检断言：

```text
lowerRouteEndY = collectorTopY - collectorThickness - branchThickness
upperRouteEndY = collectorTopY
upperStartZ - lowerStartZ = DoubleClampUpperStartZSign x branchThickness
outer diagonal Z projection = -2 x branchThickness
outer diagonal actual length >= DoubleClampOuterDiagonalMinimumLengthMm
```

这些是对已经生成的 `BusbarPlan` 输出做契约检查，并不是复制一套 `BusbarRoutePlanner`。它能及时发现配置、端口传递、选型、孔位同步或路径组装被改坏的情况；实体表面方向、孔是否真正贯穿和碰撞仍由生成后的 SolidWorks 边界框与局部三件装配检查确认。

## 14. 自动实体复验基线

2026-07-19 已实现并运行 `--verify-geometry`。该命令不重建铜排，而是读取当前装配中已存在的 `Busbar_*` 组件、装配坐标边界框和孔切除特征。正常生成完成后也会自动运行同一检查。

当前样例包含三台漏保：`630A + 400A + 400A`。一次完整生成 28 根铜排后，实体校验结果为：

```text

```

实际读取到的双排贴合面为：

```text
A: 下排/汇流排下表面 = 466mm，上排/汇流排上表面 = 474mm
B: 下排/汇流排下表面 = 406mm，上排/汇流排上表面 = 414mm
```

同时验证了：ABC 汇流排实际为 `8x60mm`、N 汇流排实际为 `5x50mm`；`4x40mm` 与 `4x30mm` 分支排的实际 X 向宽度正确；所有 `HoleCut_P*` 特征存在，且切除深度分别等于对应材料厚度 `4/5/6/8mm`。

## 15. 搭接螺栓夹紧层

双排夹接的标准件长度计算必须把三层铜排实体作为一个夹紧层：

```text
下分支排 + 汇流排 + 上分支排
```

不能分别按“下排 + 汇流排”和“上排 + 汇流排”选择两套独立螺栓，否则会低估双排夹接所需的螺栓长度。

当前最小螺纹露出量为固定 `3mm`，不按螺纹扣数计算。实际标准长度选定后，程序使用实际剩余长度参与后续电气间隙计算；`3mm` 只是最低通过条件，不是最终投影量。
